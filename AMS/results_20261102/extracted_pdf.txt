                                               VI. R EPRODUCIBILITY
   The package contains portable per-evaluation metrics, per-
stage training budgets, all selected checkpoint identities, exact
permutation distributions, generated LaTeX tables, PDF/PNG
ﬁgures, the campaign’s hash-veriﬁed source snapshot, and
the representative original video. All 450 original evaluation
summaries and veriﬁcation manifests are included. The much
larger complete per-step CSVs, all 162 videos and checkpoints
remain at the server paths recorded in the input manifest; this
supplement is not a replacement for that full raw archive.
Rebuild the numerical tables and plots with:
python scripts/build_ackermann_paper_results.py
-output . -rebuild
   The data originate from the recorded completed queue. No
new training or simulation was run for this supplement. The
ﬁnal systemd timeout ﬂag occurred during cleanup of a teleme-
try subprocess after the main process had exited successfully;
independent artifact checks veriﬁed the completed results.
